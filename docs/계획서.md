# 프로젝트

이 프로젝트는 자취방 내에 있는 사용할 수 있는 IT 기기들을 연동시켜 내 삶의 질을 높히기 위해 만든 프로젝트이다.

# 기능계획(초안)

- 전기세 + 가스비 실시간 확인
- 책장(읽은 책, 읽고있는 책, 읽을 책 정리)
- 화장지, 라면 계란 등 현재 남아있는 물품 수
- 청소 알람
- 쓰레기 처리 알람
- 월세 알람
- 강의시간 알람
- 블로그 알람

# 활용 기술

- MariaDB
- Next.js + Typescript
- Python
- fastapi

# 개발 규칙

- 각 기능별로 issue를 남겨 계획서를 미리 작성 후 개발

- 변수명은 camelCase사용
- 깃 컨벤션은 아래 표를 따름

| 유형     | 설명                                                                 |
| -------- | -------------------------------------------------------------------- |
| Feat     | 새로운 기능을 추가한 경우                                            |
| Fix      | 버그를 고친 경우                                                     |
| Design   | css 등 사용자 UI 디자인 변경                                         |
| !HOTFIX  | 급하게 치명적인 버그를 고쳐야 하는 경우                              |
| Refactor | 프로덕션 코드 리팩토링                                               |
| Comment  | 필요한 주석 추가 및 변경                                             |
| Docs     | 문서를 수정한 경우                                                   |
| Test     | 테스트 추가 및 테스트 리팩토링 (프로덕션 코드 변경 없음)             |
| Chore    | 빌드 태스크 업데이트 및 패키지 매니저 설정 (프로덕션 코드 변경 없음) |
| Remove   | 파일을 삭제하는 작업만 수행한 경우                                   |

- branch는 develop 브랜치를 default로 기능별로 feature/ 브렌치를 만들어서 개발 진행
